    01

    服务连接

    先测试连接，也可以直接测试尚未保存的内容。

    qBittorrent

    Web UI 或兼容的 API Key 认证服务

    QB
    填写 PTFlow 能访问的 qBittorrent Web UI 地址，包含协议与端口，不含内嵌凭据或查询参数。容器内的 localhost 指容器自身；远程连接请使用 HTTPS 或可信本地网络。
    用户名与密码使用 Web UI 登录；API Key 通过 Bearer 认证，要求 qBittorrent ≥5.2 或提供兼容接口的服务，并非所有旧版 Web UI 都支持。
    留空不会清除已保存的密码。
    仅 API Key 认证时使用，留空保留原值。
    密码与密钥不会回填到页面。保存或测试时留空沿用已保存值，不代表清除；填写新值才会替换，未保存的凭据仅用于当前连接测试。
    填写 qBittorrent 进程实际看到且可写的路径，不是 PTFlow 的路径。容器部署应填写容器内挂载路径；留空不发送 savepath，由下载器决定保存位置。请核对分类、默认目录与挂载配置。

    M-Team

    只查询符合条件的 Free 候选

    MT
    填写站点 API 服务地址而非网站首页，不含内嵌凭据或查询参数。生产环境要求 HTTPS；仅本机回环地址允许 HTTP 测试。
    留空不会清除已保存的 API Key。使用你自己的站点 API Key。页面不会回填已保存的密钥；留空保留，填写新值替换。连接测试使用当前草稿，不保存更改。
    仅支持不含账号密码的 HTTP(S) 代理；MT API、种子下载及重定向都走此代理，不改变 qBittorrent 连接。填写后覆盖环境代理与 NO_PROXY；留空沿用环境代理，未设置环境代理则直连。127.0.0.1 指 NAS 本机。
    查询分类
    至少选择一个分类；每轮依次查询所选分类的第一页，重复种子按 ID 更新候选池。查询只发现候选，不会立即提交下载器。
    默认 60 秒是在同一轮相邻分类查询之间主动等待，不是查询周期，也不是 HTTP 429 限流。选一个分类时没有分类间等待；站点拒绝请求会单独记录，不自动重发。
    每个所选分类向站点请求第一页最多这么多条（1–200）；返回数量由站点决定。不是下载数量，也不会自动翻页取完全部种子。
    ◇

    密钥不会通过 API 返回。测试与日志均由服务端脱敏，空白密钥意味着保留原值。

    02

    运行计划

    保存后立即重新安排。跨午夜时段会自动识别。

    启用自动运行

    关闭后暂停自动查询、添加与闲置清理；统计采样与 Free 安全保护继续运行。手动运行绕过自动开关与工作时段，但仍遵守磁盘、并发、速度、Free 与清理保护。

    自动发现、筛选并更新候选池的间隔；不等于添加种子的间隔。自动开关与工作时段都允许时才执行。
    自动核对下载器并评估候选添加的间隔；每轮保护检查通过才可能新增，不保证每轮都有下载。
    自动运行开启时的清理检查间隔；闲置移除还需启用下方清理开关。关闭自动运行后，Free 安全检查仍由采样执行。
    读取下载器全局速率、累计传输与可用空间，用于趋势及速度保护，并检查托管种子的 Free 安全。自动运行关闭或工作时段外仍采样；采样不够新鲜时不新增。
    使用有效的 IANA 时区名称，如 Asia/Shanghai；计划时段与页面时间按此时区解释，不随浏览器所在地改变。
    工作时段只限制自动查询与刷流：包含开始、不包含结束；相同时间表示全天，22:00–08:00 表示跨午夜。不会停止已有下载，也不限制采样、Free 安全检查或已启用的自动清理。
    03

    保护策略

    手动运行也遵守这些边界。清理仅针对确认托管的任务。

    容量与速率

    保留下载器报告的可用空间；空间小于或等于该值时不新增。剩余可用预算还会缩小单种文件选择。指标来自 qB 默认保存目录，不保证是自定义路径、分类目录或临时目录所在磁盘；请自行核对挂载与余量。
    统计 qB 中进度未满且未停止的全部任务，包括排队、等待及非 PTFlow 任务；不是只数正在传输的托管种子。达到上限后不新增，不会暂停其他任务。
    — GiB
    0.01–100,000 GiB · 对数刻度；精确值可在数字框输入。每个种子按完整文件从小到大选择，所选文件总大小不超过此预算与可用磁盘预算中的较小值；不拆文件，放不下任何完整文件时不启动。这不是种子总大小筛选，也不是实际磁盘占用或流量保证：BT 分片边界、临时文件、元数据及下载器预分配可能额外占用空间。1 GiB = 1,024³ 字节。
    窗口内全局上传采样的平均值大于目标时不新增（相等不阻止）。这是添加判定，不保证上传收益，也不会设置 qB 上传限速或停止已有任务。
    窗口内全局下载采样的最大值大于阈值时不新增（相等不阻止），不是当前瞬时速度或平均值。不会设置 qB 下载限速、暂停已有下载，也不是站点 HTTP 限流。
    使用最近这段时间的真实 qB 全局采样计算上传平均值与下载峰值，包括非 PTFlow 流量。窗口内无样本或最新样本超过 max(60 秒, 2 × 采样周期) 时不新增。

    候选筛选

    Free 剩余时间必须大于该值才允许下载；进入此窗口会停止托管种子的未完成文件下载并保留数据。Free 只涉及下载优惠，不免除站点 H&R、做种时长等规则，也不保证能在优惠结束前下完。
    按站点查询时的做种人数筛选；低于此值不添加，相等允许。人数可能变化，不保证实际可连接的来源或下载速度。
    按站点查询时的下载人数筛选；低于此值不添加，相等允许。用于选择潜在需求，不保证这些用户会从你这里下载。

    安全清理

    启用闲置清理

    默认关闭；开启后仅移除确认归属 PTFlow、无传输且状态允许、同时满足闲置与保护时长的任务。自动清理还需启用自动运行；手动清理也遵守此开关。关闭闲置清理不关闭 Free 安全保护。

    距离最近观测到的活动至少这么久才可清理。任何上传或下载速率大于零都会刷新活动时间；同时参考下载器 last_activity，不能只凭当前零速度判断闲置。
    从 PTFlow 确认提交、qB 添加、qB 完成时间中最晚的有效时间起至少保护这么久，不是累计实际做种时长，也不能保证满足站点 H&R。仍需同时满足闲置与状态条件。
    默认只移除 qB 任务，保留下载文件。开启后清理请求会要求下载器同时删除数据，可能不可恢复；并不扩大可清理范围。Free 安全停止不使用此选项、不删除数据。

    正在上传或下载的任务不会被闲置清理；站点规则请自行确认，任何本地保护阈值都不是站点免责保证。

    更改只在保存后生效空白密码与密钥保留已保存值。
